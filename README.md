# 마음 타로

학생용 · 일반용 · 상담자용 타로 성찰 도구 (HTML 한 파일, 설치 없음)

- 학생용·일반용: 카드를 직접 섞어 뽑고 뒤집어 봐요
- 상담자용: 실물 카드와 같은 카드를 골라 상담 포인트·탐색 질문을 함께 봐요
- AI 해석: ⚙ 설정에서 각자 Gemini API 키를 불러와 사용 (키는 이 저장소에 없으며, 각 기기 브라우저에만 저장)
- 키가 없어도 카드 뽑기와 기본 해석은 동작해요

타로는 미래를 정하는 예언이 아니라, 생각을 정리하도록 돕는 도구예요.

카드 이미지: Rider–Waite tarot (Pamela Colman Smith, 1909, public domain)
